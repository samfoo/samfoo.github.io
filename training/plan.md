# The 13-week plan

**Window:** 2026-07-06 → 2026-10-04 (Mon-start weeks).
Read [`principles.md`](principles.md) first — zones, nutrition, autoregulation, and travel tiers
are all defined there and this plan assumes them.

## Shape of the week

5 sessions: **3 runs + 2 full-body lifts**, ~45–60 min each. Climbing is a flexible bonus (see below).
A typical week, adjust days to your calendar:

| Day | Session | Notes |
|-----|---------|-------|
| Mon | **Lift — Day A** (Squat + Bench focus) | fresh start to the week |
| Tue | **Run — easy Z2** | 40–50 min, recovery pace |
| Wed | *rest / bike commute / climb* | optional climbing slot |
| Thu | **Lift — Day B** (Deadlift focus) | |
| Fri | **Run — quality** | the one hard run (progresses by block) |
| Sat | **Run — long easy Z2** | the aerobic-base builder |
| Sun | *rest / walk / mobility* | |

Rules of thumb:
- Keep ~24 h between a hard run and a leg-heavy lift where you can (don't stack Fri quality run
  onto Thu deadlifts *and* Sat long run without a genuinely easy Tue).
- **Climbing** slots into Wed or the weekend as a bonus, or *replaces* a lift's accessory work when
  you're fresh and want to climb. It's great anaerobic + grip work — but it doesn't replace the
  barbell big-3 for goal #3, so don't let it crowd both lift days out.
- The daily bike commute is Z1 NEAT — keep it, don't count it as a session.

## Running progression

You've already run 21 km, so the aerobic base is real — we grow it gently (newer runner = injury
caution) and add quality on top.

- **Easy runs (Tue):** 40–50 min Z2 throughout. This is where fat-burning + base live. Don't rush it.
- **Long run (Sat):** start ~12–14 km, build ~10%/week to **~18–20 km** by block 3, then ease into
  the test week. Drop the long run every deload week. All Z2 — walk hills to keep HR down if needed.
- **Quality run (Fri):** progresses per the table above — **strides → tempo → intervals**. Always
  10-min easy warm-up and cool-down. If a week is heavy, this is the run that becomes easy first.
- **Weekly volume:** keep total run distance climbing no more than ~10% week-to-week; deload weeks
  drop ~30%. If shins/knees/Achilles complain, hold volume flat — endurance is patient.

### The one hard rule for running

Easy days **easy**, hard days **hard**. Your data shows you're good at easy — the only new skill is
letting the tempo/interval days actually reach Z3/Z4, and keeping everything else genuinely slow.

## Benchmarks — how we'll know it worked

Record these at the start (week 1) and re-test week 13:

**Body composition** (from the scale + Garmin, trend over the week, not a single reading):
- Weight (target trajectory toward ~80 kg)
- Body-fat % trend
- Waist measurement (tape — often more honest than bioimpedance BF%)

**Endurance** (Garmin):
- VO2max (baseline ~47–48) and fitness age (baseline 40)
- Resting HR (baseline ~55)
- **Benchmark run:** a 5 km time trial, *or* average HR at a fixed easy pace (e.g. HR at 6:30/km) —
  a lower HR at the same pace = a bigger engine. Do the same test wk1 and wk13.

**Strength** (from `strength.md` log): top working weights for squat / deadlift / bench, at the same
RPE. Holding or gaining these *while* dropping ~5+ kg of bodyweight is a real win.

## Establishing your starting loads (do this week 1)

For each of squat, deadlift, bench: warm up, then work up to a **top set of 5 at RPE 7** (3 reps in
reserve). That weight is your block-1 starting "working weight." Record it in `strength.md`. Don't
test a true 1RM — no need, and not in a deficit.
